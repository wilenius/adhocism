+ I'm building a local semantic search tool for ethnographic work, on top of `qmd`.[note: qmd is an excellent search tool that combines the Best Matching 25 algorithm with vector semantic search and LLM re-ranking, all locally on your own computer.] I wanted to see which open embedding model is the best for searching, when the source document contains languages like Javanese. I built a testing harness, and compared five models: harrier-0.6b, qwen3-0.6b, bge-m3, me5-large-instruct, and embeddinggemma-300m. I had 40 example queries in Indonesian, Javanese, Finnish, and English pointed to the things I thought would be relevant results from my fieldwork data for the searches. Results, in a nutshell

	+ No model was clearly better than the other.

	+ Using embeddings clearly helps. The results were much better than only using the BM25 algorithm.

+ I was a bit surprised about not finding more performance differences for my somewhat esoteric uses, like spotting code switches and register changes in Indonesian political speech.

GPT-6.2 as a historian

+ [This post](https://generativehistory.substack.com/p/gpt-62-astra-solves-a-historical) describes how GPT-6.2 Astra made an original contribution to the history of the North American fur trade, from a single brief prompt of a historian. The author speculates that next year there might be a crisis of confidence for human historians as they realise agent systems can do things in historical research that humans cannot.
