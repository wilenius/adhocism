{{- /* Builds a lookup of tag title (lowercased) -> RelPermalink, used by post_tags.html to turn tag pills into links. Both sections are indexed because a tag is a page: content/pages/ a real Logseq page whose title happens to be a tag (en, fi, id, meta) — prose and all content/tags/ a stub generated by scripts/generate_tag_pages.py for every tag with no Logseq page behind it The generator never writes a stub for a tag that a Logseq page already covers, but pages still win here so a stale stub can't shadow real content. Call through partialCached — this walks every page in the site. */ -}} {{- $index := dict -}} {{- range site.RegularPages -}} {{- if in (slice "pages" "tags") .Section -}} {{- $key := .Title | lower -}} {{- if or (not (isset $index $key)) (eq .Section "pages") -}} {{- $index = merge $index (dict $key .RelPermalink) -}} {{- end -}} {{- end -}} {{- end -}} {{- return $index -}}
